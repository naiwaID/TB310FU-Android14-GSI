## 关键技术事实

- 机型：Lenovo Tab M9 / 启天K9，**TB310FU**，MT6769V Helio G80，arm64
- 布局：**A/B 双槽**，`super` = 8192 MB，userdata 20 GB
- 分区名带后缀：`boot_a/boot_b`、`vbmeta_a/vbmeta_b`、`vbmeta_system_a`、`vbmeta_vendor_a`
- 联想专有分区：`lenovolock`、`lenovocust`（300MB，智牛定制区）、`lenovoraw`
- **进 BROM：关机 → 按住音量加（V+）→ 插 USB**
- **进 fastboot：关机 → 按住音量减（V−）→ 插 USB → START 菜单选 Volume Down**
- 电池 5100 mAh，充电仅 10W（5V/2A），从 0 到开机要 1~2 小时

## 板上测试点丝印（拆机后才能用）

| 丝印 | 作用 |
|---|---|
| `PWRK` | 电源键：碰 GND 1~2 秒开机，保持 15 秒强制关机 |
| `V+` | 音量加：保持接 GND 后插 USB = BROM |
| `V−` | 音量减：保持接 GND 再按电源 = fastboot |
| `BAT+` / `BAT-` | 电池正负极，`BAT+` 绝不能短接接地 |
| `NTC` / `ID` | 电池温度和识别电阻 |

## 踩过的坑（别重复）

1. **备份中途拔线 → 设备假死**。mtkclient 在 DA 阶段会关看门狗，拔线后 SoC 永远停在等待状态，按键、插拔、深刷线全无效。唯一救法是物理断开电池。**备份一定要跑完**。
2. **进 BROM 用 V+ 不是 V−**。V− 进 Preloader，DAA 会拒绝未签名 DA，报 `upload_data failed 0x1d18`。
3. **卡开机动画时别用 `fastboot reboot fastboot`**。擦空 data/metadata 后进不去 fastbootd，会死锁重启。正确做法是 BROM 里 `mtk.py e userdata,metadata,cache`。
4. `mtkclient` 里 python 的 `re.MULTILINE` 解析分区表会失效（文件是 CR 换行），要按行 `splitlines()`。
5. 脚本里直接用 `tee` 写 gpt.txt，中断会覆盖成半截日志 → 改成时间戳文件 + 先写 `.tmp` 再 `mv`。
6. SourceForge 各镜像在国内基本不可用（0~20 KB/s），GSI 改从 GitHub 拿。
7. 自制深刷线（D+/GND 跨 1kΩ）**会导致握手必然失败**，因为 D+ 被拉低。测完记得拔掉。
8. 官方刷机工具白名单只有 44 个国内机型，**不含 TB310FU**，别浪费时间。
9. GSI 横屏必须 `wm user-rotation lock 1`，只写 settings 会被 app 改回 free。
10. 时区要用 `cmd alarm set-timezone`，`setprop persist.sys.timezone` 会失败。
