# 联想 启天K9 / Tab M9 (TB310FU) 刷 LineageOS 21

目标：把锁死的学习系统换成 LineageOS 21 纯净版（无谷歌、无学习机残留）。
芯片 MTK Helio G80 (MT6768/6769)，Linux 侧用 mtkclient 代替 Windows 的 SP Flash Tool。

## 顺序（每条一行，fish 里也能直接跑）

```bash
bash ~/TB310FU-启天K9/脚本/0-环境准备.sh          # 装 android-tools + USB 权限（要 sudo）
bash ~/TB310FU-启天K9/脚本/5-下载镜像.sh       # 下 LineageOS GSI，1.4G，可并行开跑
bash ~/TB310FU-启天K9/脚本/1-检测设备.sh          # 关机 + 按住音量+ + 插线 → 读分区表
bash ~/TB310FU-启天K9/脚本/2-备份分区.sh         # 备份关键分区（务必跑）
bash ~/TB310FU-启天K9/脚本/3-解锁.sh         # 解 BL + 关校验 + 清数据
bash ~/TB310FU-启天K9/脚本/4-刷入系统.sh      # fastbootd 里刷 system
```

## 按键速查

| 目的 | 操作 |
|---|---|
| BROM（mtkclient 用） | 关机 → 按住**音量+** → 插 USB → 出现日志后松手 |
| fastboot | 关机 → 按住**音量-** + **电源** |
| fastbootd | 脚本里 `fastboot reboot fastboot` 自动进 |
| 强关 | 长按电源 15 秒（无效就电源+音量-） |

## 出问题

- 卡 Logo / 开机转圈超 15 分钟：重进 fastbootd，`fastboot -w` 再重启。
- 刷 system 报空间不足：换 `...-arm64_bvN-vndklite.img.gz`。
- 彻底变砖：`bash ~/TB310FU-启天K9/脚本/5-下载镜像.sh rom` 下官方包，解开后按分区写回。
- 想回官方：官方 ROW 固件解压出 scatter + images，用 `mtk.py wl <解压目录>` 整包写。
