# 联想 Tab M9 / 启天K9 (TB310FU) 设备资料卡

## ⚡ 本机已引出的四根飞线（实测可用，2026-11-06）

主板测试点已焊线引出，颜色固定如下，**另一头永远是红线（GND）**：

| 线色 | 测试点 | 作用 |
|---|---|---|
| **红** | GND | 公共地，所有短接的另一端 |
| **橙** | V−（音量减） | 进 fastboot / 工厂模式 |
| **黄** | V+（音量加） | **进 BROM（mtkclient 必须）** |
| **绿** | PWRK（电源键） | 短按开机；长按 15 秒强制关机 |

### 常用组合（照着接）

| 目的 | 操作 |
|---|---|
| **开机** | 红+绿 碰一下 1~2 秒 |
| **强制关机** | 红+绿 保持 15 秒 |
| **进 BROM**（刷机/备份） | 红+黄 保持短接 → 插 USB，出现 `0e8d:0003` 再松开 |
| **进 fastboot**（刷 GSI） | 红+橙 保持短接 → 红+绿 碰 1 秒 |
| **进工厂测试模式** | 红+黄 保持 → 红+绿 碰 1 秒 |

### 关键教训

- **BROM 用黄线（V+），不是橙线**。橙线（V−）进去的是 `0e8d:2000` Preloader，
  该机 `DAA=True`，会拒绝 mtkclient 的未签名 DA（`upload_data failed 0x1d18`）。
- 音量减只适合 SP Flash Tool 那条路（走 Preloader + 签名 DA）。

## 关键判断依据

1. **充电慢是硬伤**：电脑 USB 口 0.5 A → 满充要 10 小时以上；原装 10 W → 约 1~2 小时才有开机电量。
2. **有振动马达**：开机若能感到震动 = 主板上电；屏幕不亮则另属显示/排线问题。
3. **库仑计**：电量统计很准，所以"满电"判断可信；也说明 PMIC 会严格按电量策略切断输出。
4. **金属后盖 + 卡扣**：拆机需均匀加热，忌金属撬片。

## 联想官方"无法开机"排查（iknow TS0106 摘要）

1. **释放残余电荷**：断开所有电源 → 连按电源键 3 次、每次 5 秒
2. **关机充电 2~3 小时**（必须插原装充电器，不要边用边充）
3. **环境温度** 10~25 ℃，低温需回温 30 分钟
4. 仍无反应 → 主板充放电电路 / 电池保护板 / 背光供电短路，需送修

## 拆机断电池（解除 DA 卡死的唯一确定性办法）

### 工具
吹风机、塑料撬片（吉他拨片/废银行卡）、小十字螺丝刀、取卡针

### 步骤

1. **拔卡托**：侧边针孔顶出 microSD 托（这也是第一个着力点）
2. **加热四边**：吹风机中低档，距机身 5~10cm，沿边框走一圈 **1~2 分钟**（手摸温热即可，别烫手）
3. **插撬片**：从卡托缺口或底部角，贴着「屏幕框 / 后盖」之间的缝插入 2~3mm
4. **沿边划开**：右边 → 底边 → 左边，会听到「啪」的卡扣声，**别用金属撬片**（后盖是金属的，容易崩漆/划伤边框）
5. **掀起后盖**：平着抬起，不要斜拽
6. **找电池排线**：主板上、电池引出的黑色/白色扁平排线，通常压在一个小金属盖下，用一颗十字螺丝固定
7. **拧螺丝 → 取金属盖 → 用塑料撬片从连接器本体垂直挑起**（不要拉线、不要拽胶带）
8. **等 30 秒**（期间不要接任何线）
9. **原样按回**，听到「咔」为准；装回金属盖和螺丝
10. **先只接充电器开机测试**（不接电脑），有震感 = 主板上电

### 打开后顺便检查
- 电池是否鼓包（鼓了就换，别再用）
- 排线接口是否发黑/氧化
- 有没有进水痕迹（白色腐蚀物）

### 如果不想自己拆
送修时直接说：「疑似电池保护板锁死 / SoC 卡在下载模式，请断开电池排线再复位」。
一般维修店几十元就能做，不需要动主板。
